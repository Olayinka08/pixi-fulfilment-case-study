Python implementation

The function below is the full implementation. It calls the OpenAI API, validates the JSON response, and falls back to human escalation if confidence is below 0.70 or the response is malformed.

import openai, json

# Confidence threshold: escalate to Ops if AI is not sure enough
CONFIDENCE_THRESHOLD = 0.70

def explain_exception(order_ref, sku, shopify_qty, warehouse_qty, email_snippet=None):
    """
    Calls GPT-4o to classify a fulfilment discrepancy and suggest an action.
    Returns a dict with keys: type, confidence, action, escalate.
    Falls back to escalation if confidence < threshold or response is malformed.
    """

    email_note = f'Warehouse email excerpt: "{email_snippet}"' if email_snippet else "No warehouse email available."

    prompt = f"""You are a fulfilment reconciliation assistant for a beauty brand.
A discrepancy has been flagged between Shopify and the warehouse dispatch file.

Order: {order_ref}
SKU: {sku}
Shopify qty: {shopify_qty}
Warehouse dispatched qty: {warehouse_qty}
{email_note}

Classify this exception and suggest a next action.
Respond ONLY with valid JSON in this exact format:
{{
  "type": "<exception type>",
  "confidence": <0.0–1.0>,
  "action": "<suggested action>",
  "escalate": <true|false>
}}"""

    try:
        response = openai.chat.completions.create(
            model="gpt-4o",
            messages=[{"role": "user", "content": prompt}],
            temperature=0.1,
            response_format={"type": "json_object"},
        )
        result = json.loads(response.choices[0].message.content)

        # Enforce confidence threshold regardless of model suggestion
        if result.get("confidence", 0) < CONFIDENCE_THRESHOLD:
            result["escalate"] = True

        return result

    except (json.JSONDecodeError, KeyError):
        # Non-JSON or malformed response: always escalate
        return {
            "type": "Parse error",
            "confidence": 0.0,
            "action": "Escalate to Ops Manager — AI response could not be parsed.",
            "escalate": True,
        }

Guardrail: AI output is always a suggestion. No record moves to Confirmed status without an explicit human decision. If confidence falls below 0.70, or if the model returns non-JSON output, the exception is auto-routed to the Ops Manager — no action is taken.
