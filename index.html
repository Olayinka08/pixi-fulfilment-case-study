Technology Architecture

Sources
Data Inputs
  • Shopify Fulfilment API (webhook)
  • Warehouse dispatch CSV (SFTP or email)
  • Warehouse email replies (IMAP)
Bronze Layer
Raw Ingestion
  • Python ingest script (scheduled)
  • Timestamped, source-tagged rows
  • Immutable — never overwritten
Silver Layer
Standardise & Match
  • Normalise order refs, strip prefixes
  • Canonical SKU mapping
  • Deterministic match engine
  • Exception flagging rules
AI Layer
Exception Triage
  • LLM: GPT-4o or Claude API
  • Structured prompt per exception
  • Confidence score (0.0 to 1.0)
  • Suggested action and reasoning
Gold Layer
Review Interface
  • Exception dashboard (web UI)
  • Approve / Reject / Escalate per row
  • Human sign-off required to export
  • Full audit log with timestamps
Audit Trail
Traceability
  • Every match decision logged
  • AI explanation stored separately from approval
  • Reviewer name and timestamp on each row
  • Immutable export file with hash

Tool choices: Python for portability and data-team familiarity. LLM API (not a local model) to keep maintenance low. No production Shopify or NetSuite access required in pilot — files used directly.

AI Case Study · Page 2

AI Judgment, Business Outcomes & Pilot Plan

Where AI adds value, where it must not decide, and how to measure success.

AI Judgment Framework

Deterministic Rules (no AI)
  • Exact order ref + SKU + qty match: auto-confirm
  • Duplicate order ref in same file: flag immediately
  • Order ref in Shopify but absent from warehouse: open exception
  • Quantity difference greater than 0: always escalate
  • Value difference greater than £0.01: flag for Finance
AI Adds Value (LLM)
  • Parse free-text warehouse email for discrepancy explanation
  • Classify exception: partial shipment, split delivery, timing gap, admin error
  • Match non-standard order refs (ORD-1234 vs #1234)
  • Summarise pattern across multiple exceptions
  • Draft follow-up question to warehouse in structured format
Human Judgment Required
  • Accept or reject any AI explanation before it affects the record
  • Decide if a partial shipment is acceptable for NetSuite posting
  • Approve final export file — no auto-posting ever
  • Escalate to warehouse operations manager
  • Override any AI classification at any time
⚠ Critical Guardrail: AI Explanation ≠ Confirmed Match

AI output is stored as a suggestion, not a resolution. The exception status remains Unresolved until a named human reviewer explicitly approves it. The audit log records both the AI explanation and the human decision separately. A reviewer cannot approve an exception without viewing the raw evidence alongside the AI suggestion — the interface enforces this sequencing.

How to Measure

Time Saved
Measure
  • Log reviewer time per session (start/end timestamp)
  • Compare 4-week pre-pilot vs. 4-week post-pilot average
Accuracy
Measure
  • Rate of AI suggestions overridden by human
  • Post-posting error rate in NetSuite (target: 0)
Exceptions
Measure
  • Count exceptions unresolved at end of each week
  • Track age of oldest unresolved exception
Operating Cost
Measure
  • LLM API cost per week (logged per call)
  • Target: API cost less than 10% of time saved value

Assumptions: current process = 4 hrs/week across Ops and Finance combined; blended hourly cost = £35/hr; LLM API cost ~£2–5/week at current GPT-4o pricing for ~50 exceptions/week. Validate against actual Pixi team time logs in pilot week 1.

Pilot Plan

1
Week 1–2: Shadow run

Automated pipeline runs in parallel with existing manual process. No decisions made from AI output yet. Compare outputs at end of each week.

2
Week 3–4: AI triage, human decisions

Ops lead uses the review interface with AI explanations visible. Manual process runs simultaneously as a check. Both methods timed.

3
Week 5: First live export

Finance approves NetSuite posting file from new system for the first time. Manual file produced in parallel as a backup.

4
Week 6: Review and decide

Review all four metrics. If acceptance criteria met, retire the manual process. If not, identify gaps and extend the pilot.

Acceptance Criteria

  • Human review time reduced by at least 50% vs. pre-pilot baseline
  • Zero NetSuite posting errors attributable to the new process in weeks 3–5
  • All exceptions resolved within 24 hours of file receipt
  • Ops lead rates AI exception explanations as "useful" or "very useful" in at least 70% of cases
  • Full audit trail present for every matched and unmatched record
